"Check-internet" extension options

In this extension badge used like indicator to inform status http status code frome direct or remote request. It's only triggers when browser request not succesfull (status code not in range 200-299). In some cases when chrome prefetch pages, extension can check them and return they code.

Badge text xCODE. CODE - any possible http status code like 200 or 404. X can be (examples):
D200 - direct response.
R404 - response redirection from remote server.
P500 - remote server don't get response.
Err - remote server not response.
D. . . - all ok but status not catched.
R. . . - pending remote request.

Also you can add urls to request response status code on one click like https://example.com/ or your router http://192.168.0.1.
